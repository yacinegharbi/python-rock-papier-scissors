# Rock Paper Scissors

A simple command-line implementation of the classic Rock Paper Scissors game in Python.

## Features

- Play against the computer
- Simple text-based interface with emoji support
- Input validation
- Play multiple rounds

## Requirements

- Python 3.6+

## How to Run

```bash
python rockpapiersecissores.py
```

## How to Play

1. Run the script
2. Choose your move: 
   - `r` for Rock 🪨
   - `p` for Paper 📄
   - `s` for Scissors ✂️
3. The computer will randomly choose its move
4. The winner is determined and displayed
5. Choose whether to play again

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choice = Tie
